# SwiftCart 🛒

SwiftCart is a lightweight academic e-commerce web application developed to demonstrate **core Java web technologies** and **clean MVC architecture**.  
This project is designed strictly for learning and academic evaluation purposes.

---

## 📌 Project Overview

SwiftCart focuses on:
- Understanding how Java web applications are structured
- Implementing MVC + DAO architecture
- Practicing JSP–Servlet interaction with JDBC
- Clean UI separation using JSP and CSS

⚠️ **Note:**  
This is **not a real e-commerce platform**.  
No real transactions, payments, or commercial activities are involved.
---

## 🛠️ Technology Stack

### Frontend
- JSP
- HTML5
- CSS3

### Backend
- Java
- Java Servlets
- JDBC

### Database
- MySQL

### Architecture
- MVC (Model–View–Controller)
- DAO (Data Access Object)
